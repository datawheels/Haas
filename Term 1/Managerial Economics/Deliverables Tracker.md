### How to read this file
- Every date below is **already converted to Pacific local time**. Canvas's own API reports deadlines in UTC, and naively quoting that UTC date is wrong — e.g. a Canvas `due_at` of `2026-10-22T06:59:59Z` is **Oct 21, 11:59:59 PM Pacific**, not Oct 22. All times here have already had that conversion applied.
- A deadline does **not** line up with when its class happened — Problem Set 2 covers Block 2 material, but its deadline (Oct 21) is right before Block 3 starts, well after Block 2's classes are over. Don't assume something is done just because the related classes are in the past.
- 🔴 = still open / not yet done. ✅ = deadline has passed. ❓ = mentioned/implied by the syllabus but not yet posted to Canvas.
