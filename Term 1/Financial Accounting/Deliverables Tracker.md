### How to read this file
- Every date below is **already converted to Pacific local time**. Canvas's own API reports deadlines in UTC, and naively quoting that UTC date is wrong — e.g. a Canvas `due_at` of `2026-10-22T06:59:59Z` is **Oct 21, 11:59:59 PM Pacific**, not Oct 22. All times here have already had that conversion applied.
- A deadline does **not** line up with when its class happened. **This is the main trap in this course specifically**: Short Quiz 2 and Homework 2 cover Block 2 material, but their deadline (Oct 21) is well after Block 2's last class (Oct 3) — it's timed to land right before Block 3 starts instead. It is very easy to see "Block 2 is over" and wrongly assume Block 2's quiz/homework are done too. They are not, until Oct 21.
- 🔴 = still open / not yet done. ✅ = deadline has passed. ❓ = mentioned by the syllabus but not yet posted to Canvas with full detail.
